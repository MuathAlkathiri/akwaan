# Rakkibha visual candidate selection

The implemented runtime projects one private reference and private candidate
views. The spoken operation may be route selection, code reconstruction,
constraint satisfaction, defuse logic, or a missing piece; all resolve as an
actor-local candidate choice. Candidate local IDs have holder-local meaning.

This runtime representation must not make `MISSING_PIECE` the default authoring
pattern. Declare the actual interaction in `authoring.rakkibha.interactionPattern`.
