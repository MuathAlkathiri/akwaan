# ChallengeType: Same Wavelength

## Experience Goal
Create a playful moment of simultaneous teammate agreement.
## Social Dynamic
Teammates privately choose from the same bounded options without communicating.
## Player Emotion
Anticipation, recognition, surprise, and laughter.
## Interaction Pattern
Prompt → simultaneous private selections → joint reveal → match check.
## Thinking Pattern
Predict shared preference through safe team knowledge.
## Success Pattern
Options are equally plausible and a match feels personal but harmless.
## Failure Pattern
Sensitive content, socially forced answers, unmatched free text, or one dominant option.
## Input Contract
Each teammate submits one option ID privately.
## Resolution Contract
Exact option-ID equality; no external truth.
## Content Structure
Three reusable ContentItems with two to four bounded options.
## Allowed Content Patterns
- `exact-match`
## Content Safety Rules
Exclude income, bodies, religion, romance, intelligence, humiliation, and family-discomfort topics.
## Media Compatibility
Optional thematic media that does not signal a preferred answer.
## Scope Compatibility
Prompt and options must remain naturally inside the selected Scope.
## Validation Rules
Verify private simultaneity, option balance, safety, exact resolution, replayability, and World framing.
## Anti-patterns
External truth, sensitive comparison, obvious group norm, open text, or answer signaling.
