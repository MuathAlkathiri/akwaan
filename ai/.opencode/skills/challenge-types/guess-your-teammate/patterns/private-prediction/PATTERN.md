# Pattern: Private Prediction

- Experience goal: test safe teammate familiarity through prediction.
- Interaction shape: private selection plus independent private prediction.
- ContentItem shape: World-framed prompt and two to four option IDs.
- Answer payload: `{ "resolution": "answer_prediction_equality" }`.
- Machine resolution: answerer option ID equals predictor option ID.
- Constraints: harmless, balanced, reusable, quickly understood.
- Compatibility: all non-excluded Scopes.
- Media: optional and neutral.
- Tension levers: authentic tradeoffs and recognizable play styles.
- Anti-patterns: sensitive inference, reputational harm, free text.
- Valid example: predict which familiar character a teammate would choose.
- Invalid example: predict a teammate's religious belief.
