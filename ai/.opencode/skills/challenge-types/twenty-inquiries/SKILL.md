# ChallengeType: Twenty Inquiries

## Experience Goal
Create cooperative deduction through disciplined information seeking.
## Social Dynamic
One player privately sees a target and may respond only yes or no while teammates investigate.
## Player Emotion
Curiosity, urgency, convergence, and shared discovery.
## Interaction Pattern
Private target → bounded yes/no exchange → team submission → reveal.
## Thinking Pattern
Partition possibilities, ask efficient inquiries, and infer identity.
## Success Pattern
The target is familiar, the candidate space is bounded, and responses are deterministic.
## Failure Pattern
Subjective responses, obscure targets, unbounded domains, or accidental target exposure.
## Input Contract
Target-holder receives private target data and yes/no controls; team submits one target ID.
## Resolution Contract
Exact target-ID match within the timer and inquiry limit.
## Content Structure
One bounded ContentItem target set supporting a 45-second cooperative exchange.
## Allowed Content Patterns
- `bounded-identity`
## Content Safety Rules
Use harmless thematic targets, never personal secrets or sensitive attributes.
## Media Compatibility
Optional private target media; public screen shows only the candidate boundary and progress.
## Scope Compatibility
Requires a stable, familiar, and finite entity set.
## Validation Rules
Verify target familiarity, deterministic yes/no facts, private visibility, candidate bounds, and automatic resolution.
## Anti-patterns
Open domains, disputed attributes, trivia-only targets, target data sent publicly, or human adjudication.
