# Signature ChallengeType Registry

Every World must eventually own exactly one exclusive, auto-resolvable
Signature mechanic. No assignment is final yet, so this directory intentionally
contains no invented mechanic.

A future Signature skill must satisfy the complete ChallengeType contract,
declare `isExclusive: true`, define continuous or discrete item structure, fit
the three-item pacing envelope, and register scoring centrally. A World cannot
ship until its Signature mechanic is assigned and validated.
