# Scope Knowledge Profile: spot-the-error

## Identity / Boundaries
اكتشف الخطأ — Infer an objective rule, then find what violates it. a rule must be inferable from the material itself, and exactly one element must break it. Two steps, always: infer the rule, then locate the breach.

## Strong Content Territories
Strong: an intruder in a consistent set, a broken ordering, an invalid member of a pattern, a component that contradicts the rule the rest establishes.

## Weak / Boring Territories
Weak: sets where more than one element arguably breaks the rule, rules only an expert would infer, 'errors' that are really trivia gaps.

## Evidence Opportunities
consistent sets, ordered sequences and annotated diagrams; the rule must be inferable without a caption.

## Terminology / Aliases
Use the player-facing Arabic name **اكتشف الخطأ** in copy; use the canonical slug
`spot-the-error` in every technical identifier. No other name or slug is approved.

## Ambiguity Traps
a second unintended violation; a rule with more than one reading; an error that is a fact-check rather than a rule breach.

## Scope-Specific Taste
A good item here makes the player say «آه، شفتها» — the satisfaction comes from
the solve itself, never from having known something. Every item must survive
both `PUZZLES_WORLD_NO_TRIVIA` and `PUZZLE_ITSELF_IS_THE_CHALLENGE`.
