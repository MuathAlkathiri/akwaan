# Scope: Visual Puzzles (ألغاز بصرية)

- `scopeId`: `puzzles.visual-puzzles`
- `worldId`: `puzzles`
- Boundary: Spatial reasoning, geometric shape decomposition, visual pattern completion, counting intersecting figures, isometric projection, color/shade logic, and image-essential deduction.
- Included: Text-described visual geometry challenges, 2D/3D mental rotation, unfolded cube faces (nets), hidden overlapping triangle/square counts, optical geometric deductions, and image-based media intent puzzles.
- Excluded: Ordinary trivia with a decorative background picture; puzzles where the visual is irrelevant to the question.
- `excludedChallengeTypeIds`: []
- Media Intent: For image-native mechanics (Bomb / visual ركّبها), declare clear, precise media intents defining the visual schema.
