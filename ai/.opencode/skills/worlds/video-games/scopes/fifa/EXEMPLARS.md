# Scope Exemplars: FIFA (EA Sports FC)

## REJECTED: FUT Draft Token
- **Item**: "في الألتميت تيم، وش فايدة هذي التوكن؟" -> "تدخلك FUT Draft / Draft Token" (Image: Draft Token)
- **Status**: REJECTED
- **Reason**: Shallow administrative/UI chore. Identifying a raw consumable or a basic menu button does not create a strong, recognizable gameplay moment unless that object is central to a highly memorable, high-stakes interaction. 
- **Taste Lesson**: Avoid generic FUT menus and consumables. Prefer evidence that triggers nostalgia, intense gameplay memories, or specific high-value card archetypes (e.g., Timed Finishing UI, iconic Chemistry Styles if presented cleanly, iconic Walkout animations).
