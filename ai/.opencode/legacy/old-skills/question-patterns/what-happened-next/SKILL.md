# WHAT_HAPPENED_NEXT

## Purpose

Test ordered recall or observation immediately after a bounded moment. A video
ending before the answer is ideal; an image or text anchor may work when fair.

Do not use when many later events qualify, the clip shows the answer, or the
event boundary is unclear.

Validation: answer must be the next meaningful beat, not any later consequence.
Arabic example: `ماذا حدث مباشرة بعد فتح الباب؟`
