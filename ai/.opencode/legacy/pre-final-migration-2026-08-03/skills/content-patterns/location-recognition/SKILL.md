# LOCATION_RECOGNITION

## Purpose

Recognize a distinctive location, map, district, stadium, or in-world place.
Image/video/map is preferred; text is valid for meaningful location knowledge.

Do not use generic rooms/roads, signage containing the answer, or arbitrary
filming locations.

Validation: the visible or contextual details uniquely support one place.
Arabic example: `ما اسم المكان الذي وقعت فيه هذه المواجهة؟`
