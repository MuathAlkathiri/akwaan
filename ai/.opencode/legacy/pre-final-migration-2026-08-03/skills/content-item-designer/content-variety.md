# Content Pattern Variety

A generated ContentItem set must vary the actual tested memory, not only wording.

Track:

- Content Pattern;
- Gameplay Pattern;
- primary focus;
- event cluster;
- answer;
- media channel;
- Scope coverage.

Do not concentrate the set around one protagonist, one famous map, one episode,
one weapon class, or one recognition formula when suitable variety exists.

Pattern repetition is allowed only when the tested asset, answer, and observation
are genuinely different.
