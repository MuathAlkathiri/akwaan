# Akwaan Content Health

Health reports are derived outputs, not source-of-truth configuration. Regenerate
`catalog-health.json` and `subject-health.json` after the first complete run of
the updated ContentItem pipeline.

New health dimensions should include World, Scope, compatible Challenge Types,
answer mode, Content Pattern, primary focus, media type, readiness blockers,
and RYO coverage. Legacy difficulty and 200/400/600 distributions are invalid.
