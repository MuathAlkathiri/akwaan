# Distributed Information Validation

Run `python3 .opencode/validators/validate_distributed_information.py <paths>`. A valid draft or ready item passes; ready status additionally requires the author safety confirmation.

The validator enforces canonical routing, native object payloads, supported inner modes, exact A/B/C structure, safe 2+1 merges, exact team sizes, confirmation, deterministic truth, privacy leakage checks, no truth in mechanic data, and no notes-based payload workaround.
