# Retired Distributed Information Authoring Material (World-Clue Model, 2026-08-09)

The product direction reset redefined ركّبها / Distributed Information as a
cooperative Puzzle World challenge: one shared puzzle divided into secret
participant fragments plus a team instruction. The previous active model in this
directory treated each item as three private semantic World clues (A/B/C
segments) whose `candidateSets` geometry isolated one answer; it depended on
canon-first World facts (e.g., Naruto) and required every canonical 2+1 holding
to be non-solving.

This directory preserves that retired authoring material for reference:

- `skill/` — the retired World-clue Skill, schema, and `three-segment-race`
  Pattern.
- `validate_distributed_information.py` and `test_distributed_information_fixtures.py`
  — the retired validator and its fixture suite.
- `DISTRIBUTED-INFORMATION.md` — the retired validator contract doc.
- `examples/` — the retired valid examples and negative fixtures.
- `smoke-distributed-information-naruto-forms-2026-08-08/` — the retired
  Naruto-forms smoke batch (six high, three medium-high items).

None of this is active input. The legacy boundary in `README.md` applies; the
retired concepts (`candidateSets`, A/B/C candidate intersections, 2+1 semantic
holding safety, World clue synthesis, `three-segment-race`) must never re-enter
active authoring guidance.
