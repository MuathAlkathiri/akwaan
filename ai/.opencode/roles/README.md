# Akwaan Roles

Each Role receives one manifest, read-only upstream files, and one exclusive
output destination. The standard handoff is:

```text
Experience Plan → Focused Research → Draft → Review → Optional Assets
→ QA → Human Approval
```

Mechanic selection and interaction planning occur before research. Later Roles
report repairs to the owning Role rather than overwriting its output. No Role
imports or publishes.
