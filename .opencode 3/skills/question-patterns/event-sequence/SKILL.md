# EVENT / SEQUENCE / TIMELINE / ARC

## Purpose

Test a memorable event, ordered steps, chronology, or story/competition stage.
Media is optional; video is strong for observed order.

Do not use arbitrary episode numbers, unclear parallel timelines, or multiple
questions from the same Event Cluster merely by changing the angle.

Validation: define boundaries, order, and accepted answer set; record Event
Cluster and arc/season/tournament in the Coverage Ledger. Arabic example:
`رتب هذه الأحداث من الأول إلى الأخير.`
