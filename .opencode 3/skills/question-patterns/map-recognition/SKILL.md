# MAP_RECOGNITION

Recognize a named map or playable space from distinctive geometry, landmarks,
routes, lighting, or gameplay context. Prefer clean gameplay frames or bounded
clips. Reject loading screens, minimap/title labels, posters, fan art, custom
maps presented as official, generic interiors, and frames from the wrong title
or version. Context may name the game only when needed to remove ambiguity.

Arabic example: `ما اسم هذا الماب؟`
