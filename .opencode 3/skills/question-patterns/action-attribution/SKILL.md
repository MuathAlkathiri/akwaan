# WHO_DID / WHO_STOPPED / WHO_SAVED / WHO_KILLED / WHO_BETRAYED

## Purpose

Attribute a meaningful action to its actor. Image/video is preferred when the
action must be observed; text is valid for memorable event recall.

Suitable knowledge: bounded canonical actions and participants. Do not use when
the setup names the actor, several actors qualify, or the question is merely an
obvious relationship.

Validation: define the event/timeframe without naming the answer; distinguish
direct action from ordering or enabling it. Arabic example:
`من أوقف الهجوم قبل وصوله إلى القرية؟`
