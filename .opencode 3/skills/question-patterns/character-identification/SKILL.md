# CHARACTER_IDENTIFICATION

## Purpose

Directly identify a non-saturated, meaningful character from one visual or
audio recognition channel. Required Media: clear image/video/audio.

Do not use protagonists, title/mascot/top-recognition characters, promotional
portraits, biographical text clues, or more than 15% of a batch.

Validation: apply Recognition Saturation, different character per use, natural
in-world Asset, and no independent clue channel. Arabic example:
`من هذه الشخصية؟`
