# Lammah Style Guide

Read `../../knowledge/LAMMAH-DESIGN-BIBLE.md`.

- Write in the requested player language with natural, direct phrasing.
- Use the minimum context needed for fairness.
- Use consistent Catalog names, character names, and established aliases.
- Prefer character names over actor names for story questions.
- Do not manufacture difficulty through syntax, negation, tricks, or vague
  pronouns.
- Do not put explanations in the answer field.
- Do not expose source searches, filenames, captions, internal notes, or the
  answer to players.
- State the required count for Group Recall and keep its answer boundary clear.

This Skill controls presentation. It does not change the output schema, batch
plan, validation rules, or Catalog facts.
