# PERK_RECOGNITION / EQUIPMENT_RECOGNITION

Recognize a named perk, equipment item, or modifier from a distinctive icon,
model, placement, activation, or in-game effect. State title context only when
needed to disambiguate reused designs. Reject visible answer text and generic
items shared across titles without sufficient context.

Arabic examples: `ما اسم هذا الـPerk؟` / `وش الأداة الظاهرة في الصورة؟`
