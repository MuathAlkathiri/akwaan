# Pattern: Exact Match

- Experience goal: reveal whether teammates independently align.
- Interaction shape: simultaneous private selection from shared options.
- ContentItem shape: safe prompt plus two to four option IDs.
- Answer payload: `{ "resolution": "option_id_equality" }`.
- Machine resolution: all required selections equal.
- Constraints: balanced options, harmless stakes, Scope framing.
- Compatibility: all non-excluded Scopes.
- Media: optional and neutral.
- Tension levers: authentic preference tradeoffs.
- Anti-patterns: sensitive topics, obvious socially desirable option, free text.
- Valid example: choose which game mode the team would start first.
- Invalid example: choose which teammate is least intelligent.
