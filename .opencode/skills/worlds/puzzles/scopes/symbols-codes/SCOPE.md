# Scope: Symbols and Codes

- `scopeId`: `puzzles.symbols-codes`
- `worldId`: `puzzles`
- Boundary: symbol and code puzzles: substitution, mapping, letter-number
  codes, simple ciphers, and secret-word games presented as puzzle material.
- Included: symbol-to-letter maps, letter-to-number codes, substitution rules,
  simple cipher keys, and hidden-word tricks.
- Excluded: real cryptographic material, actual passwords, and any code that
  needs a lookup table the team cannot hold in mind.
- `excludedChallengeTypeIds`: []
- Pattern exclusions: pure luck items; every code must be decryptable from the
  fragments alone.
- Safety: no real secrets, personal codes, or security material.
