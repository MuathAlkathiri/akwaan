# Deprecated Lammah Architecture

Files under `.opencode/legacy/` belong to the architecture that preceded the
Challenge-first Product Bible. They are retained only for historical reference,
auditability, and deliberate manual recovery of useful knowledge.

New agents must never read, route through, or depend on these files unless a
human operator explicitly assigns a legacy-recovery task. No new content may be
generated from them directly.

`old-skills/` preserves the former Skills tree as one internally connected
unit. It includes the deprecated Catalog/Subject hierarchy, Question Pattern
registry, point-mapped difficulty guidance, category-oriented generation,
Generated Batch orchestration, and utilities coupled to those concepts.

Moving the complete tree prevents partial dependencies from leaking into the
new active Skills hierarchy while keeping relative references inside the old
tree intact. Recovery means extracting a fact or principle, validating it
against the current Product Bible, and rewriting it into an appropriate World,
Challenge, Scope, Tool, Role, or Workflow file. Never move a legacy file back
into active use unchanged.
