# OBJECT_RECOGNITION / WEAPON_RECOGNITION

## Purpose

Recognize a meaningful object or weapon from appearance, use, owner-independent
scene context, or consequence. Image/video is normally required.

Do not use generic objects, visible labels, or wording that semantically rebuilds
the answer name. Avoid repeating recognition gameplay across many objects.

Validation: visually distinctive, one accepted identity, Media-dependent.
Arabic example: `ما اسم السلاح الظاهر في الصورة؟`
