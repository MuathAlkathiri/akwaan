# Akwaan Style Guide

Read `../../knowledge/AKWAN-CONTENT-BIBLE.md`.

- Write natural, direct Arabic.
- Use the minimum context required for fairness.
- Keep prompts short enough for the mechanic's timer.
- Use established Arabic names and aliases consistently.
- Prefer character names over actor names for story content.
- State units clearly for numeric estimates.
- Do not expose filenames, sources, search queries, or internal notes.
- Do not place explanations inside answer payloads.
- Do not manufacture challenge through syntax, negation, or vague pronouns.
- Do not mention legacy points or difficulty labels.
