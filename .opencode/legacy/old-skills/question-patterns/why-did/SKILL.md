# WHY_DID

## Purpose

Test a canonically supported motivation or cause. Media is optional; use it only
when the scene is needed to identify the decision being explained.

Suitable knowledge: explicit motives, decisions, causes, and consequences.
Do not use for inferred psychology, opinions, or multi-cause ambiguity.

Validation: one concise supported reason; no answer in setup; distinguish cause
from goal. Arabic example: `لماذا رفضت الشخصية عرض الصلح في هذا المشهد؟`
