# HUD_RECOGNITION / UI_RECOGNITION / ICON_RECOGNITION

Use a HUD, minimap style, scoreboard, lobby, inventory/loadout screen, killcam,
or icon when its visual system supports one intended game, screen, state, or
named element. Crop or obscure title/answer labels without removing the fair
distinguishing evidence. Reject generic interfaces, unreadable crops, and
answer-bearing text.

Arabic examples: `هذا الـHUD من أي لعبة؟` / `أي شاشة تظهر هنا؟`
