# GAME_IDENTIFICATION

Identify the title/installment from a reliably distinguishing HUD, UI, handling
style, hitmarker, scoreboard, lobby/menu cue, announcer, map environment, or
other gameplay Asset. Reject shared/generic visuals and sounds, visible title
names, and clues that distinguish only a franchise rather than one title.
Aliases must resolve to the same verified official title.

Arabic example: `هذه الواجهة من أي جزء؟`
