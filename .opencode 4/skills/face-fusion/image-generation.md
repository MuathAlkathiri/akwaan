# Generated Image Asset Contract

Face fusion is a provider-neutral future `generated_image` Asset type. This
Skill does not configure or call a provider, API, SDK, or external service.

Requirements:

- photorealistic
- symmetrical lighting
- neutral background
- looking at camera
- no text
- no logos
- no jersey emphasis
- chest-up portrait

A future completed Asset should preserve recognizable features from both people.

Do not create a split-face.

Do not create half-and-half edits.

Create one believable fused identity.

If one person dominates the blend, reject it for regeneration by a future
configured provider.

## Pair Quality

Choose pairs that create an enjoyable challenge.

Good pairs:

- Messi + Cristiano
- Neymar + Mbappé
- Zidane + Ronaldinho

Avoid:

- two nearly identical players
- two very obscure players
- two players with extremely similar faces

Do not fabricate a local file or mark a face-fusion question complete. Completion
requires an actual local image that can be opened and passes `validation.md`.

The pair itself should be entertaining before any image is generated.
