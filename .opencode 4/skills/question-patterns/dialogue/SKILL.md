# COMPLETE_QUOTE / DIALOGUE

## Purpose

Test memorable dialogue by completion, attribution, response, or scene meaning.
Use text, audio, or bounded video through one primary recognition channel.

Do not use obscure lines, copyrighted passages longer than necessary, ambiguous
translations, or text that names the speaker when attribution is asked.

Validation: exact enough to be recognizable, accepted variants bounded, no
subtitle leakage. Arabic example: `أكمل العبارة: «لن أتراجع عن ...»`
